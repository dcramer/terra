# tools/git

Checks of git history that the hooks run, and the hook's checks run elsewhere.

- `undone.ts`, run by `.githooks/pre-push` (D431): `node tools/git/undone.ts [range]` (default `origin/main..HEAD`) warns, a line an undo, of a commit that silently undoes another commit of the last 48 hours outside the range: it deletes every line that commit added to a file (at least three) and puts back what it replaced, or the commit only added, while its message names neither the file nor the commit. Moves and `spike/` don't count. It never fails; nothing printed means clean. Node 22.18+, no dependencies; `node --test tools/git/undone.test.ts`.
- `remote-check.ts`, run by `.githooks/pre-push` when `TERRA_REMOTE_CHECKS=1` (the environment over `.env`; D37, D445): instead of `cargo xtask check` here, it runs that check on the render worker (`cargo xtask remote-render`, a check: a CPU job that may start while the box drains for a bench, but waits out a bench's timed run, docs/render-worker.md) at each commit the push sends, over what the commit changed since its merge-base with origin/main (`--base`), prints the check's own lines and fails the push when the check fails or the worker cannot be reached; the stages' logs come back to `~/.cache/terra-review/remote/check-<sha>/target/check/`. For a machine that must not build. `node --test tools/git/remote-check.test.ts`.
- `guarded.ts`, run first by `.githooks/pre-push`: `node tools/git/guarded.ts <remote> <url>` (the hook's own arguments) exits 0 when the push goes to origin, by name or URL; any other push, such as remote-render's job and update refs to the render worker (D445), skips the hook's checks, which guard landing (D37). `node --test tools/git/guarded.test.ts`.
- `lfs.ts`, run by `.githooks/pre-commit` (`--staged`) and `.githooks/pre-push` (`--push`, the commits on stdin not yet on origin; D525): fails, naming the files and the fix, when a file `.gitattributes` puts in Git LFS is committed whole rather than as a pointer, reading git alone so it works where git-lfs is missing. Its `objects(rev)` lists the LFS objects a commit points to, which the render worker's client rsyncs to the box. `node --test tools/git/lfs.test.ts`.
