# Directions

Proposals for the direction of the game as a whole: what kind of game it is, what is going on in its worlds, and what the player does there. Each is one candidate, not the plan; the developers name them, compare them, and adopt at most one. What any of them settles is recorded in [decisions.md](../decisions.md) as usual.

The docs one level up each cover one part of the game, whichever direction is chosen.

| Proposal | Status | In short |
|---|---|---|
| [A living world](living-world.md) (working name) | Being considered (D89) | A sandbox with RPG in it, closer to Enshrouded, with *He Who Fights With Monsters* as a core basis: magic pools and makes monsters, settlements live with it, you hold ground with bases, outposts and recruits, and find your own way. |
