# Proposals

Numbered proposals, each one candidate rather than the plan. The developers compare them and adopt what they choose; what a proposal settles is recorded in [decisions.md](../decisions.md) as usual, and the docs one level up are brought in line.

**Construction** proposals set how what is built is made and drawn, under building.md.

**Game design** proposals cover the game as a whole: what kind of game it is, what is going on in its worlds, and what the player does there. At most one is adopted. The docs one level up each cover one part of the game, whichever is chosen.
