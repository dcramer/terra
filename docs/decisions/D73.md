# D73: Agents as players

Area: People and the tribe · Owner: Design · By: Developers · Status: Decided

The game can be played headless, by an agent alone, through the same command line and remote protocol as QA (D69); an MCP server only if a client needs one. The agent is a client like any other and keeps to the same rules.

## Why

Said by the developers on 2026-10-10. How it sees and acts is a proposal in [multiplayer.md](../multiplayer.md#agents-as-players); whether it is for us or for players too is open.
