# D51: Server-first multiplayer

Area: The game as a whole · Owner: Design · By: Developers · Status: Decided

The game always talks to a server, which decides everything and sends each player what is near them. For friends playing together the server runs inside one player's game; for a persistent world it runs alone. Both are the same code. Make a handful of players work first, then measure larger worlds before promising them.

## Why

Agreed by the developers on 2026-10-10 as the safest way. It keeps a large persistent world possible without building all of it now. See [multiplayer.md](../multiplayer.md).
