# D49: How we work from here

Area: The game as a whole · Owner: Design · By: Developers · Status: Leaning

Larger design docs come before implementation. Experiments stay small and are not a substitute for a design.

## Why

The developers said on 2026-10-10 that it would probably be better to work on larger design docs than to implement things one after another. AGENTS.md treats it as a rule.
