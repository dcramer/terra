# D74: Swimming and breathing

Area: The player and survival · Owner: Design · By: Developers · Status: Decided

The character can swim, using stamina for now. Under water, breath is used up as it is on a world with thin or no air: one rule for anywhere the air cannot be breathed. No set limit on depth: water should be flexible.

## Why

Said by the developers on 2026-10-10. Needs an animated swim, and water you can be in, which the sea (D75) already gives. See [survival.md](../survival.md).
