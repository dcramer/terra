# D353: No old saves

Area: Building · Owner: Tech · By: Developers · Status: Decided

Only the save format of now is read: a game save (`play::save`, version 2) or a base's snapshot (`terra_build::save`, version 2) of any other version is refused before anything of it loads, said as "saved by an older build; start a new game", never converted. The readers of older formats are gone: shortcut lists, walls on edges and rooms (D152), D209's roof sections, glass (D225), D231's four-bit shapes, items saved by model file. Amends D160, D201, D231 and D241.

## Why

The developers on 2026-10-15: "we dont care about old saves"; "we dont even care about saves right now".
