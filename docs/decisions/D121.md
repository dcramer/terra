# D121: Languages

Area: Tools and workflow · Owner: Tech · By: Developers · Status: Decided

Code is Rust or TypeScript. The game and anything it shares is Rust; tooling outside the game (scripts, CLIs, the token stats' worker) is TypeScript on Node, run directly with no build step. Short shell scripts are fine as glue (launching a program, chaining commands); anything with real logic is TypeScript or Rust. No new Python or other languages, except code that must run inside a program that only speaks Python, such as Blender scripts. Python no longer used is deleted rather than ported.

## Why

Said by the developers on 2026-10-11: they did not want one-off scripts in assorted languages, and the project already needs Node for Cloudflare and Rust for Bevy. Two languages are fewer to know, set up and check. TypeScript over Rust for tooling: it needs no compile and adds no dependencies to the game's workspace, which suits glue around services that change under us.
