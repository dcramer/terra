# D355: Destruction leaves a blueprint to rebuild

Area: Building · Owner: Design · By: Developers · Status: Decided

Later, not in the current baseline (D333): what is destroyed or collapses without the player taking it apart with the build tools (an attack, the ground giving way) is not lost; each lost cube is left as a blueprint in its place, so it can be built again. Taking apart with the hammer stays as D193 has it, leaving nothing. Until this is built, collapse and damage work as D305 says, including plans hanging from what falls going with it.

## Why

The developers on 2026-10-15: "future design note, not part of this scope: destruction shouldn't be permanent. that is, we'll want destruction to leave like a blueprint in its place when its not done intentionally by the player with the build tools (so it can be rebuilt)".
