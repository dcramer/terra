# D45: Contracts for harvest and water

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

Every harvest is an operation that returns a yield. Water is asked for by position, not read as one global number.

## Why

Built and in use since 2026-10-10 (`terra_core`): operations return a `Yield`, and the ground says where the water is by direction. Keeps D43 open, and water that differs by place possible, at no cost: one sea is a constant answer to the same question pools would answer.
