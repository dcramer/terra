# D82: Token stats

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Decided

Each developer's Claude token use on this repository is recorded by a Cloudflare Worker with D1, fed by a script that reads Claude Code's transcripts and runs from a Claude Code hook after each turn. Totals are on a public page. A session counts if it started in the repository or a worktree. Each message is stored once, keyed by its API id, with totals per person, day and model. Shared key; no accounts. Tripo credits count in the cost too: our Tripo scripts record each task's credits in a local file the same script sends, stored once by task id; API credits are priced at their list price and Studio credits at the subscription's price per credit.

## Why

Asked for by the developers on 2026-10-10, at the least possible cost and never counting twice. Workers and D1 on the free plan cost nothing and stop rather than bill at a limit. Transcripts repeat a message many times, including in resumed conversations under other ids and on other days, so totals per day or per conversation would double count; per message they cannot. Plain Node, no dependencies, so it runs anywhere Claude Code does. The worker reports its errors to Sentry with `@sentry/cloudflare`, its one runtime dependency, since otherwise a failing worker goes unseen until someone looks at the page. See [tools/token-stats](../../tools/token-stats/README.md).
