# D2: Multiplayer

Area: The game as a whole · Owner: Design · By: Developers · Status: Decided

Multiplayer, with no PvP. Friends playing together is the small case of a persistent server holding up to a thousand (D52).

## Why

Too expensive to retrofit, so it is in the architecture from the first build. Built server-first (D51). Was "co-op, up to 4 players" until 2026-10-10.
