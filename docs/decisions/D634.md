# D634: The iso experiment's biomes are data files on one shared kit, judged toward realism by an adversarial loop with a no-loss ratchet

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Decided

In the isometric experiment (crates/terra_iso, iso-kit), a biome is a data file, `crates/terra_iso/biomes/<name>.ron`, never code (D136): it names its layout, ground layers and blend masks, scatter sets, decals, water, light preset, weather, effects and life, and the shared kit in `crates/terra_iso/src/kit/` draws it. RON because Bevy already reads it (no new crate in the lock) and a comment can carry each number's reason. A new kind of thing (a layout, a scatter shape, a weather) is kit code with a test; a biome that needs code shows the kit is missing something, and the kit is fixed, never the biome. The kit holds no genre's assumptions: a neon street at night in the rain is made the same way as a ruin, from the same layers, water, effects and lights.

Quality is judged by an adversarial loop, one command: render every biome's still (and on request its film) on the worker, measure each against its own references (`tools/iso-art/stats.ts`), then a harsh judge, briefed to find faults, scores each against the references with its gaps; fix and judge again until it approves (7) or two rounds bring no gain. A blind pairwise judge against the biome's last kept still says only whether a change won; it is never the quality verdict. The kit's ratchet: a change is kept only if no biome loses its pair (a clear or strong loss, or a slight loss twice with the order swapped); a biome whose still did not change ties without a judge. Each round's scores, pairs and stats are kept in a history the command prints.

The references are realistic: aerial and drone photographs at the camera's height and angle, matched per biome (a ruin, a forest, a marsh, a city street at night in rain), beside the most realistic top-down and isometric game frames found (The Ascent for the city). The bar is a game look that leans into realism: believable materials, light, scale, weathering and detail, not a photo match and not stylised fantasy; the judge rewards each step toward realism, faults anything cartoonish, toy-like or plasticky, and still requires that figures, hits and paths read from the camera. The stylised ARPG store frames (D628's round) stop being the bar; every biome was re-baselined against the new references on 2026-11-07.

## Why

After seven to thirteen jobs a biome tuning its own ground, water and effects, each biome stood near 5 of 10 ([research/2026-11-05-iso-arpg-art-pipeline.md](../../research/2026-11-05-iso-arpg-art-pipeline.md)); building those once as shared systems makes a biome cheap and lets it inherit the quality. The developer: "let's do this - start wokring on those so we have strong base and build out a loop for that. make sure that we can do non-fantasy as well - iamgine like a cyberpunk and etc." On the bar: "you should use adversary loops for it when you are trying to assess quality. we don't mean to compare to baldurs gate anymore, not for graphics, the name of the game is high quality, realistic topdown game", and "realistic meaning leaning into realism". A pairwise judge alone saw gains while the absolute score stalled (judging.md), and a single biome's pair is noisy, so the ratchet needs a loss on its own biome, confirmed when slight, before a kit change is undone.
