# D29: How state is shared

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

World changes are operations applied in the server's order (D21). Gameplay runs on the server's fixed tick (D138); a world simulation runs only on the server and is sent as snapshots (the threaded `terra_sim` is parked with terraforming). Moving things are sent as positions and smoothed.

## Why

The simulation is small enough to send, which removes any need for players to compute identical floating-point results.
