# D80: Options menu

Area: The player and survival · Owner: Design · By: Developers · Status: Decided

An options menu with the settings players expect, including audio and remapping keys.

## Why

Said by the developers on 2026-10-10. Proposed contents in [player.md](../player.md#options). A first version is built in the game (`terra_game`): every control is looked up by action, and settings are a plain `name = value` file in the player's settings folder, read with no new dependency and ignored by scripted runs so they stay repeatable.
