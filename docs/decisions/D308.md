# D308: QA films

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Decided

`cargo xtask qa <scenario> --set <kit>|mixes|all` films a scenario the same every time in a set of kits: a scenario is a file in `tools/sandbox/qa/` (sandbox options, remote calls on given frames, camera moves written against a set); a set is each wall kit in `assets/data/kits/` with its roof, read from the folder, and `mixes`. A scripted run makes the calls on their frames through the remote's own methods (`--calls`), so a film and a script driving a run live do the same thing; it waits for every section, and debris, before each frame, so its frames are the same every run. A first pass live learns how many steps each fill takes in the set, so the film paces them; the film is every second frame at 30 a second with each stage's name; the same calls in a benchmark run write every frame's time (`--frame-times`) and each edit's time to the screen, three times (`--runs`) on a machine as quiet as it gets (D185), the middle run by its 99th percentile written with every run's numbers, their spread and a verdict. Building in them costs nothing (`--free-build`: every cost met, claims still holding), and the camera is placed in the base's own metres (`build.look`); a camera a script holds aims no tool. Outputs in `shots/qa/`, an index page of the latest.

## Why

The developers, 2026-10-14: "make sure the building systems is fluid, works well, everything adjusts as it gets built (can we preprogram a sequence to capture a video of it that we can do in the future repeatably?)", then "same thing for destruction. i want easily repeatable QA things that will capture videos, and be able to do it per set", and "just the core 'can we construct it with infinite pretend resources'". Calls on frames rather than a script stepping the clock live: a live script's round trips are not frame-locked, and the frames drawn while it waits differ run to run. The castle is put up as the player's base (`build.example`) so an edit to it takes the hammer's path to the screen and is timed there, which no scene did.
