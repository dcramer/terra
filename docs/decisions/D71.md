# D71: Developer tools

Area: Tools and workflow · Owner: Tech · By: Developers · Status: Decided

Tools that help refine each system, scriptable as well as usable by hand, and easy to use: a developer can read what one shows at a glance without knowing how it works, and it explains itself where it is used. Those that need the renderer are testbeds in `terra_sandbox`, everything else in `tools/<name>/` (D133), each started from `cargo xtask`. The model workbench is built: it lines models up side by side against simple terrain, held and worn, through the same animation. Still wanted: a way for a developer to review models and leave notes the agent reads.

## Why

Asked for by the developers on 2026-10-10; review added on 2026-10-11, to test models and let a person QA them. On 2026-10-13: "make our debug tools easy to use. that's a requirement". Built and in use since 2026-10-11: the workbench, the yard, the remote, and the prop, icon, character and Tripo tools. See [development.md](../development.md#developer-tools).
