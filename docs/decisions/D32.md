# D32: Terrain meshing library

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

The `transvoxel` crate, in `terra_voxel`; port Voxel Tools' mesher if re-meshing on detail changes proves costly.

## Why

The crate bakes seam stitching into each mesh. Built and in use since 2026-10-11: a chunk meshes in about 3 ms, within the terrain brief's 6.
