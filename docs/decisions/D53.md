# D53: Collision

Area: Engine and code · Owner: Tech · By: — · Status: Open

Required: collision shapes that work with voxel terrain, bases and objects, for players, creatures and aiming. The developers want collision boxes on everything, used for placing things as well as for walking. How is not designed. The leaning in D33 (a physics engine for shapes, with players asking voxel data directly) is untested.

## Why

Asked for by the developers on 2026-10-10. The game (`terra_game`) still uses stand-in arithmetic, such as circles on the ground for bodies and trees. See [engine.md](../engine.md).
