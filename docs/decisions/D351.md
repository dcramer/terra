# D351: Building's code a module a concern, and what nothing uses deleted

Area: Building · Owner: Tech · By: Agent · Status: Decided

`terra_build` keeps one concern a module: the snapshot of now in `save` (older formats refused, D353), the quick tools' shortcuts and wall tiles in `shortcuts`, the hammer's ray in `ray`, the base and its cubes in `lib.rs`. Code, data fields, options and remote parameters nothing uses are deleted, not kept (AGENTS.md); one weld and one tangent path, `mesh.rs`'s `Indexed`, which the game draws with. What is left, ranked, with its order: [research/building-code-health-2026-10-15.md](../../research/building-code-health-2026-10-15.md).

## Why
