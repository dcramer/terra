# D452: Combat is held by a scorecard of criteria and a ratchet on their numbers

Area: Lore, magic, combat and growth · Owner: Tech · By: Agent · Status: Decided

What combat must get right is data, `tools/combat/criteria.json`: a row a criterion, each with what a player would notice, its bar, its source (an Enshrouded target, D180, or a decision), the check that measures it, whether it is cheap (seconds, CPU) or heavy (the GPU film), and whether it is measurable yet (what it needs, if not). `cargo xtask combat` measures every cheap one (the move set's timings in real seconds against `tools/combat/refs/enshrouded.json`'s targets, the move check on every body template, D447, and the fight's rule tests, D449 among them) and prints a line each; `--film` adds the duel film's checks.

A criterion's number is how far it is outside its bar, so worse is always more. `tools/combat/baseline.tsv` holds each one's number, and the scorecard fails only where one is worse than it is held at: a change may leave a criterion below its bar, never make it worse, unless the same commit raises its row with `cargo xtask combat --raise "<why>"`. A gain is banked by the full run on main alone (`cargo xtask nightly`, `--lower`), as every ratchet is (D414); its lowering is carried onto a main that moved only if nothing the scorecard reads (`COMBAT` in `xtask/src/scope.rs`) changed. `clip.ts --into` runs the scorecard after writing a set and puts every file back when it is worse. The cheap scorecard is a stage of `cargo xtask check --all`; the film is a continuous check on main (D398, `tools/continuous/checks.json`). The failing criteria, ordered by what a player notices most (`noticed`, 5 most), are the task list, kept in the combat skill (`.agents/skills/combat`): a job (D538) takes one, works until it passes or two jobs pass without a gain, and banks it.

## Why

The developer, 2026-10-24: "do we have the right pipeline to incrementally improve this where we know we wont regress as we get things right? and do we know what the task list of things we need to get right are? my goal would be to break this down so we can advance consistently and reliably." The checks existed (moves.ts, terra_motion's duel test, the duel film's checks, the Enshrouded targets) but nothing held a gain: no single score, no baseline, nothing on main, and the task list lived in one agent's handoff. The fire sheet's held baseline (D415) and the artifacts ratchet (D414) already do this for their areas; combat now does it the same way.

A miss rather than the raw number makes every criterion read one way (larger is worse) whatever its bar, so a range such as a timing's can be ratcheted from either side. Passing rows are held too, so a criterion that passes cannot slip back unseen. The film is heavy (four GPU runs, minutes), so it runs on main after a change lands, not before.
