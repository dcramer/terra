# D52: How many players a world holds

Area: The game as a whole · Owner: Design · By: Developers · Status: Decided

A thousand concurrent players on one persistent server is what everything is built toward. It is a test each decision has to pass, not a promise for a date. The world they share is fully procedural and has to be very cheap to compute, send and store.

## Why

Set by the developers on 2026-10-10, raised from "ideally 100" earlier the same day. It replaces the limit of four in D2. Nothing has been measured at any scale; what it asks of the architecture and the design is in [multiplayer.md](../multiplayer.md).
