# D412: A design call is settled by the developers

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Decided

The docs check fails a decision with Owner Design and Status Decided unless it is By Developers (`tools/docs/docs.ts`). An agent's design call is Leaning, a working assumption, until the developers settle it; a call they leave to an agent is still theirs to mark Decided. The ten marked Decided by agents before the rule (`SETTLED_BY_AGENTS`: D171, D178, D194, D229, D233, D252, D253, D298, D313, D364) are listed for the developers to confirm or reopen; the list only shrinks.

## Why

Agents settling design calls recurred in every goals review (2026-10-13 to 16), and AGENTS.md already says design is the developers'; the developers asked on 2026-10-18 for one cheap rule in the docs check. Eight of the ten quote the developers leaving the call to an agent, D233 and D364 do not; relabelling who decided is not an agent's to do, so they wait for the developers.
