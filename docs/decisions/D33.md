# D33: Physics

Area: Engine and code · Owner: Tech · By: Agent · Status: Leaning

Avian for rigid bodies. The player and creatures query voxel data directly instead of using collision meshes.

## Why

Avian is active, but is untested here; its latest release (0.7) is for Bevy 0.19, not yet 0.20. The voxel-query approach worked in the Godot demo.
