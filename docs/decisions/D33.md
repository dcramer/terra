# D33: Physics

Area: Engine and code · Owner: Tech · By: Agent · Status: Leaning

Avian for rigid bodies: loose objects, ragdolls and the physics layer of movement (movement.md stage 7). The player and creatures are not Avian bodies. They are moved by our own character controller (D53), which queries voxel data directly instead of using collision meshes.

## Why

Avian is active, but it is untested here, and its latest release (0.7) is for Bevy 0.19, not yet 0.20. The voxel-query approach worked in the Godot demo. The character controller must run on the server without Bevy (D28), so it cannot be an Avian body. Amended 2026-10-24 when D53 was decided.
