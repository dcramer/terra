# D128: How equipment fits every body

Area: Art, characters and sound · Owner: Tech · By: Agent · Status: Leaning

Every item fits every body by contract, not by fitting per character: one base body and skeleton (D112); clothing and armour made once on it, as the faces it covers pushed out or as pieces bound to its surface, loose parts to a helper; each follows any body by the shared skeleton's proportions and carries the base's build morphs, copied by a tool, rigid parts riding one bone; one mesh per item shared by every wearer; each says which body patches it covers, which are then not drawn; a template where an item fails gets that item's own model by exception. Rigid worn things made once in a socket's space; held things once to the hand socket's axes. Checks run on every item on every template and at each parameter's limits. See [characters.md](../characters.md).

## Why

Researched on 2026-10-11 and 2026-10-12 ([character-creators.md](../../research/character-creators.md), [one-mesh-for-every-body.md](../../research/one-mesh-for-every-body.md), [modern-character-variety.md](../../research/modern-character-variety.md)) after gear fitted object by object clipped and sat wrong. The developers answered on 2026-10-12: the standard slots (D64) and no layers for now. Making each piece on each base body worked but cost a generated model per item per body; the developers asked for a way that is not items times bodies, and from how modern games do it.
