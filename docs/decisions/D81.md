# D81: Debug menu

Area: Tools and workflow · Owner: Tech · By: Developers · Status: Decided

An in-game debug menu, switched on by a flag at launch and opened with the backtick key, for debugging tasks such as warping the player. Absent unless the flag is given.

## Why

Asked for by the developers on 2026-10-10 (the key was "maybe"). Should share its commands with QA for agents (D69), so anything the menu does an agent can do. See [development.md](../development.md#debug-menu).
