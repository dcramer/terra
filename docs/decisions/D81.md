# D81: Debug menu

Area: Tools and workflow · Owner: Tech · By: Developers · Status: Decided

An in-game debug menu, switched on by a flag at launch and opened with the backtick key, for debugging tasks such as warping the player. Absent unless the flag is given. Its first page is every live tunable (D547): a searchable list grouped by prefix, a slider within each one's range, its help line and a reset; warp, give, time of day and weather come next.

## Why

Asked for by the developers on 2026-10-10 (the key was "maybe"). Should share its commands with QA for agents (D69), so anything the menu does an agent can do. Its first page, on the review desk on 2026-10-27, asked whether the menu should show a slider for every live tunable: the developers picked "Sliders for every tunable" (recommended: the same list the agents drive over `r tune`, so nothing is built twice). See [development.md](../development.md#debug-menu).
