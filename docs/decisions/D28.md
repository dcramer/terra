# D28: How the code is split

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

Anything that must be the same for every player lives in plain Rust crates that do not depend on Bevy (`terra_core`, `terra_gen`, `terra_voxel`, `terra_build`, `terra_items`, `terra_climate`, `terra_sim`; `terra_net` when networking starts). Only the applications, `terra_game` and the `terra_sandbox` test environment, use Bevy, `terra_world`, the world on screen the game stands on (D198), and the crates D407 cuts from the game, each on those under it: `terra_bases`, the base on screen, and `terra_walker`, the walker layer, so far.

## Why

Fast tests with no GPU, a headless host, and Bevy's frequent releases touching one crate. The simulation crate already moved engines unchanged.
