# D137: How a player's actions reach the game

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

Each player has an `Intent` component: the actions they hold and press, the wheel, where they aim, and whether their hands are on a screen. Gameplay reads a player's intent and acts for every player; it never reads the keyboard. This machine writes its own player's intent from its keys and mouse; a server will write everyone else's from what their games send. What a player carries, learns and is told names them (`Belongings::of`, `Did`, `Told`).

## Why

Mine to decide, for D51: a server runs the same gameplay for every player and a client predicts its own with it, which only works if input is per-player data. It is the pattern of leafwing-input-manager's `ActionState`, Overwatch's command frames and Unreal's player input.
