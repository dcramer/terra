# D579: The game's front screen

Area: The player and survival · Owner: Design · By: — · Status: Open

Should the game open on a front screen of its own (a title screen) with Continue, New game and Creative, as shipped games do, leaving the launcher (D575) only the build's choices? Is Creative (D494) chosen there, or when a world is made, as a world's mode? Does New game keep the old world, several worlds side by side, rather than replace the one save? Recommended: a front screen once there is more than one world to choose; until then the launcher holds the choices, and New game asks before it replaces the save. [launcher.md](../launcher.md#open-questions-for-the-developers-d579-d580).

## Why

The developer, 2026-10-29, asked for a launcher with continue, new game and creative. Those are a player's choices, which in a shipped game live in its own front screen; the launcher needs them now because the game has none.
