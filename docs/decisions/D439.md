# D439: A body plan is a data file

Area: Art, characters and sound · Owner: Tech · By: Agent · Status: Leaning

A creature's body plan is a file, `art/creatures/plans/<plan>.json`: its chains and their roles (spine, neck, tail, legs by kind and side, wings, fins, arms), each chain's bone count and shares, joint limits, weight zones, its pose sheet, its gaits and its check's thresholds; a kind's `creature.json` names its plan and overrides only what differs ([creature-rigs.md](../creature-rigs.md#1-body-plans-as-data-d436-d439)).

## Why

Today each kind's joints and fixes (a stag's carpus, a deer's `haunch`) are typed into its own file after a failure, so a new kind repeats the old failures. Spore and Unreal's IK Rig carry motion across bodies by labelled chains; a new kind is data, not code (D136).
