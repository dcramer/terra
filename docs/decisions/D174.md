# D174: Felling trees

Area: Worlds and realms · Owner: Design · By: Developers · Status: Decided

Trees behave as in The Forest: chopped down, and all of it seen. Proposed in [biomes.md](../biomes.md#felling-a-tree): a notch deepens with each blow, the tree tips away from the cut and falls through small plants, its trunk lies in logs where it fell (D140), branches and leaves scatter, and a stump stays to regrow (D150). Felling is one operation the server decides; the fall is shown on each machine and lands the same everywhere; generated trees are made in parts for it.

## Why

Said by the developers on 2026-10-12: "trees we're going to need to behave like The Forest btw where we can chop them down etc and that's all visual". The Forest is already an inspiration for how logs are got (D85).
