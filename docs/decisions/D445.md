# D445: Renders run on a GPU box that takes jobs from draft GitHub releases

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Leaning

An agent's heavy render (a trailer cut or its stills, a sheet, a bench, a scripted offscreen shot) can run on a second machine with a bigger card: `cargo xtask remote-render [--rev <sha>] -- <command>` queues a job as a draft GitHub release `render-<job>` holding the commit and the command, and a worker in a container beside the CI agent's (`tools/ci`, D411) takes it, runs it in its own checkout at that commit, and uploads what it wrote under `~` and any `--collect` paths to the release, which the client downloads into `~/.cache/terra-review/remote/<job>/` ([docs/render-worker.md](../render-worker.md), [tools/render-worker](../../tools/render-worker/README.md)). The worker only pulls; it runs only commits on origin's branches, never a fork's; the job's command runs without the token. When it runs is a setting: only while nightly is not running (the default) and, if set, only within a window of hours. One job at a time; a job's files are kept 7 days.

## Why

The developers, 2026-10-23: "i am thinking ill set up my other headless PC with beefy gpu up with that docker image, and you can run builds there too in the off times when the main CI/CD isn't running (or we can run it on a schedule or something...)" and "when you wanna record a video, you push code, queue it with that docker image, what revision it has to run, what it has to run etc. and it will give you back an actual file link or something/artifacts". Rounds lose most of their time waiting for the one 10 GB card (D319). A self-hosted GitHub Actions runner was the least code, but GitHub advises against one on a public repository and D411 keeps Actions off the box; an HTTP API on the LAN needs an open port and its own authentication. A draft release can be made and seen only by those with push access, so it is the queue, its access control and the file store at once, with the token and `gh` already in use. Leaning until a job has run on the real box.
