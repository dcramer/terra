# D69: QA for agents

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Decided

The game's QA is reachable by our coding agents: scripted runs, and live over Bevy's remote protocol through a command line, `tools/sandbox/remote.ts`, with methods the game defines (press keys, step the clock, wait on what the run says, read a digest of the state, set a scene up). Checks read what is true from the game rather than the screen. An MCP server only if a client that cannot run commands needs one. Off in release builds.

## Why

Asked for by the developers on 2026-10-10. On 2026-10-12 they left the shape to me. Every engine's agent tooling converges on the same core, and Unity now builds a CLI with MCP as one client of it; a CLI costs an agent no context until used and composes with scripts, and the work that matters is in the game's methods, not the transport.
