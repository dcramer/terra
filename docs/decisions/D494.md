# D494: Creative and survival

Area: Building · Owner: Design · By: Developers · Status: Leaning

A world is played in one of two modes. **Creative** has infinite resources: everything costs nothing, and it is what the developers test with. **Survival** pays every cost from what is gathered and delivered (D141, D491). What else creative changes beyond construction (harm, hunger, flight) is not chosen yet. In code the mode would replace the yard's free building and `--free-build` (`terra_building::act`), so a test runs creative and the game survival.

## Why

The developers, 2026-10-25: "we should have a mode, creative vs survival, and creative has infinite resources, which is what we'll use to test a lot". As Space Engineers 2's creative and survival. Leaning until the developers say it is settled.
