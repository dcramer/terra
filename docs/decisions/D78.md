# D78: Weather

Area: Worlds and realms · Owner: Design · By: Developers · Status: Decided

There are weather systems, and weather differs by world. What weather there is, and what it does to the player, are open. Players can forecast it, mostly by looking; technology and magic can add to it (2026-10-12).

## Why

Said by the developers on 2026-10-10. See [worlds.md](../worlds.md#weather); proposed in [climate.md](../climate.md): weather as a function of the world's seed and time, so the server sends only the time.
