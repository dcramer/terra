# D26: Where the simulation runs

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

The threaded world simulation, `terra_sim`, runs on its own thread, at a requested rate, never inside the render frame; the game takes a short lock to read or change it. It is parked with terraforming (D89). Gameplay runs on the fixed tick (D138).

## Why

Running it inside the frame dropped the demo to 7 fps at x100. On a thread, x100 (6,000 ticks a second) costs the frame nothing.
