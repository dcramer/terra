# D502: No building in a dungeon, and its rock cannot be dug

Area: Worlds and realms · Owner: Design · By: Agent · Status: Leaning

Players cannot build inside a dungeon, and its walls, floors and stairs are a rock that cannot be dug, so the one shared copy (D498) keeps its layout for everyone and stays as it was cleared (D499). The realm's ground around it is dug and built on as anywhere (D20, D94).

## Why

The developers on 2026-10-25, asked whether players can build and dig in a dungeon and whether it is kept: "idk about 6, we can do sensible default and change it later." This is that default, following the games the developers named (D497). Valheim does not allow building inside its crypts and troll caves; players use mods to lift the restriction ([Steam discussion](https://steamcommunity.com/app/892970/discussions/0/3948029052444645225)). Enshrouded keeps building and terrain changes only inside a flame altar's area and resets everything outside it ([Steam discussion](https://steamcommunity.com/app/1203620/discussions/0/4206993639701216512)). It also follows our rule that building is within claims (D94), with claims kept clear of a shared place as they are of villages (D265). The developers may change it.
