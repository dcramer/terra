# D42: Engine build order

Area: Engine and code · Owner: Tech · By: Agent · Status: Leaning

A small foundation (shared contracts, then the generation toolkit), then four tracks in parallel: terrain; a walkable stand-in world; things on the ground; networking. See [engine.md](../engine.md).

## Why

A working plan, not a commitment. A stand-in planet computed from the terrain formula let everything except the terrain itself be built before voxels existed. Separate crates keep parallel work from colliding. The voxel terrain is now built (`terra_voxel`) and the game walks on it, so the stand-in world has served its purpose.
