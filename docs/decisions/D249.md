# D249: No options for one-offs

Area: Tools and workflow · Owner: Tech · By: Developers · Status: Decided

A command-line option, flag, experiment or tool is added only for work that will come up again. A one-off, such as one scene to picture or one thing to check, is done with what exists: the existing options, driving a run live over the remote protocol (`place`, `look`, `shot`), or a throwaway script that is not committed. When nothing that exists can do it, ask before adding one. Builds on D71: general tools for the work we keep doing, not for each case.

## Why

The developers: "generally we don't wanna overly add options for one offs, we should make that into a policy."
