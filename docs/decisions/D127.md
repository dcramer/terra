# D127: Many of everything

Area: The game as a whole · Owner: Design · By: Developers · Status: Decided

A core principle: assume a large quantity of every kind of object in the game, because it is procedurally generated. Every system is built to perform, and stay modular and flexible, with many of each kind of thing and many kinds: items, gear, creatures, characters, props, places. Adding one more kind is data, not code; nothing is written for one particular object.

## Why

Said by the developers on 2026-10-12, as a core part of a procedural game, while gear was being fitted to the characters. Builds on D39 (procedural generation almost everywhere) and D58 (the game modelled in ECS).
