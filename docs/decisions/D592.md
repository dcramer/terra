# D592: Characters are saved on the server

Area: The game as a whole · Owner: Design · By: Developers · Status: Decided

A character's record is kept by the server it plays on, with the world, not on the player's machine, so the server can trust what a character holds (D51, D471). A player-hosted world keeps its friends' characters with it.

## Why

The developers, 2026-11-01, asked where a friend's character lives and what happens when the host leaves: "characters get saved on the server".
