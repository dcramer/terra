# D83: Items in code

Area: Items and crafting · Owner: Tech · By: Agent · Status: Decided

The rules for items and containers live in an engine-free crate, `terra_items`. A container is a component on the entity that holds it; the items inside are data in that component, each with an identity, not entities of their own; an item loose in the world is an entity. Every change is an action the server checks with the same function the client uses to predict it. See [items.md](../items.md).

## Why

Mine to decide. Inventories are state every player must agree on, so they stay out of Bevy (D28). Items as data inside a container keep saving and sending a player's inventory one small piece of data, and keep D58: what is in the world is an entity, and what you carry is state of you. Built and in use since 2026-10-10; the game's inventory has run on it since 2026-10-11.
