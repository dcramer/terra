# D374: What changes with the world reaches plant shaders in one shared buffer, not their materials

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

The world's wind (D255) and where the climate's maps lie (D327) are written each frame into the buffer every foliage and grass material already shares for parting (`terra_world::parting`, D271), as games keep such globals in one buffer every plant's shader reads (Unreal's material parameter collections); a material keeps only what is its own (how much it sways, which card is which kind). The climate's maps are painted again in place, the same images, and a material reading them is changed only when what it is told of them changes. A plant material that follows something of the world does it this way.

## Why

Bevy specializes again every entity drawn with a material that changes: each wind change and each repainting of the maps cost some 20 ms of the render thread over two frames, the QA clips' worst frames after the edits themselves (measured 2026-10-15).
