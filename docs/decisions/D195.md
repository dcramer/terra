# D195: How the construction system is built

Area: Building · Owner: Tech · By: Agent · Status: Decided

As [building-plan.md](../building-plan.md) says: `terra_build` split into modules a concern (cubes in sections of 16, operations with checks and inverses, ground, support, rooms, cost, kits, layouts for runs, blocks, trims, roofs and ground, walking, saves); layouts are pure functions giving piece instances in grid units, so the server needs no art; in the game, a plugin a concern, sections as entities, layouts on the worker pool, built pieces merged per section and material, ghosts instanced, far meshes from the pieces' lowest detail; snapshots plus operations; property tests over random operations, live remote commands and a `village` bench. In order: the block-module spike, the model, layouts, drawing, plans and building, then shapes, loss and repair, materials, networking.
