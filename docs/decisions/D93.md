# D93: Rich systems, little on screen

Area: The game as a whole · Owner: Design · By: Developers · Status: Decided

A principle: the game is rich with systems but somewhat realistic. You do not have a magic display of every piece of information, as you would not in life; you learn things by looking, doing and being told. Some compromises are made so it stays fun.

## Why

Said by the developers on 2026-10-11. The developers added the same day that there will still be some on-screen display and character stats; D93 bounds how much, it does not remove it. See [gameplay.md](../gameplay.md#no-hand-holding).
