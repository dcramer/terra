# D120: Scripting Tripo

Area: Art, characters and sound · Owner: Tech · By: Agent · Status: Decided

One command-line tool, [tools/tripo](../../tools/tripo), does everything the Studio web app does to a model (images, views, models, texture, retopology, segmenting, UVs, rigging, animation, export, import) on the Studio subscription's credits, through the app's private backend. TypeScript on Node with no dependencies (D121); every command prints the project it worked on so the next can take it. The bake-off's API client is retired.

## Why

The subscription's credits are what we pay for, and Studio is where Tripo's newest models and tools are; one tool means one place to fix when Tripo changes its requests, and anyone, person or agent, can run it with nothing to install. Every request was captured from the app or read from its code, and every command was run ([research/tripo-studio-api.md](../../research/tripo-studio-api.md)).
