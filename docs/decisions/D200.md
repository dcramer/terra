# D200: How the timber kind is drawn

Area: Building · Owner: Design · By: Developers · Status: Decided

Timber is drawn as generated long members (`terra_build_mesh::timber`): a profile swept along each run the layout gives, shaped by the kit's numbers and each piece's seed, displaced and textured by real materials from the pipeline, with sawn ends and chinking. Round logs in their bark (A) are the log kit, each log varying by its seed in thickness, taper, bend, the turn of its section and its colour; hewn timber (B) is a second profile of the same code, for beams, planks and squared timber. A new timber kind is a kit file (D136). Not the Tripo log models, which are gone, and not the block kinds' surface (D197). Another exception to D177, as D197 is. See [research/timber-walls.md](../../research/timber-walls.md) and [building-kits.md](../building-kits.md#how-pieces-are-made-d177-d197-d200-d251). To be compared with hand-made log pieces on D251's system. Amended by D290: timber kinds are materials of the coursed pattern, their numbers in the pattern and their pack.

## Why

The developers, shown the spike (2026-10-13) with the recommendation "A, with more variation per log (thickness, taper, bend, colour by seed); B's code kept as a second profile for beams, planks, squared timber": "Ok lets complete the task. Dont stop to tell me what is next." Earlier they asked for timber that "doesn't have to be a literal log if we can't make that work but it has to be thematic and look beautiful", procedural and extensible as data.
