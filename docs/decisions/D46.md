# D46: A sandbox for experiments

Area: Tools and workflow · Owner: Tech · By: Developers · Status: Decided

`terra_sandbox` is the test environment: it launches the game, and holds the testbeds (scenes that try one thing) and the developer tools that need the renderer, switched on from the command line. The game's code, and the shell every build runs under (window, launch options, scripted runs, frame timing, the remote protocol), are `terra_game` (D133).

## Why

The developers wanted somewhere to experiment that is neither gameplay nor terrain. The game then grew inside it as its `play` experiment, and the shell with it; on 2026-10-12 both moved to `terra_game`, leaving the sandbox what it was meant to be. Was Leaning, with whether the sandbox's parts become the game's shell undecided.
