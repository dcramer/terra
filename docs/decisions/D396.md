# D396: Code health is gated, not reviewed

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Decided

The classes of code-health fault the reviews kept finding by hand are stages of the full check (`cargo xtask check --all`, scheduled on main since 2026-10-19, D37), together well under a second:

1. **Sizes** (`xtask/src/sizes.rs`, `cargo xtask sizes`): no Rust file under `crates/` or `xtask/` over 1,000 lines and no function over 150, its `fn` line to its closing brace, a function written inside it included. What was over when the ratchet began is in `xtask/sizes-baseline.tsv`; an entry may shrink or go, never grow, and nothing is added to it. A failure names what to split and how; `--lower` only lowers the baseline, and only the scheduled full run lowers it (D414). Functions are found by reading the source (strings, characters, lifetimes and comments skipped), checked against rustfmt's layout over every function in the repository.
2. **One definition** (`xtask/src/primitives.rs`): a shared primitive lives in the lowest crate every user can depend on and is called from there; its constants anywhere else in the Rust fail the check, with the function to call, and so does a function of its defined again by name, for a primitive with no telling constant. Its table holds the 32-bit hash mixers (lowbias32 and the prospector's) and SplitMix64's finaliser, all in `terra_gen::hash`, and the `smoothstep` easing, `terra_gen::smoothstep`.
3. **Drift between the guides and the code** (`tools/docs/docs.ts`): every `cargo xtask <task>` that docs/, the skills, AGENTS.md or a tool's README names is a task, and every repository path in a skill's code spans is there, or is somewhere git ignores, where a tool writes.

## Why

The fifth goals review (research/goals-review-2026-10-16.md, findings 3 and 5) found again what the code-health note (research/building-code-health-2026-10-15.md, R10 to R13) had found: monoliths regrown, the same hash mixer written out in a dozen files, docs naming what no longer exists. A review a week finds them after they spread; a gate at each commit stops them where they start. 1,000 lines a file and 150 a function sit above what most of the code is (129 entries were over at the start, most in building and the game's systems), so the limits bind only on what is already hard to read.
