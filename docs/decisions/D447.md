# D447: The fight's rules in a plain crate, its clips checked by tools that build nothing

Area: Lore, magic, combat and growth · Owner: Tech · By: Agent · Status: Decided

The move runner's rules leave `terra_creatures::melee` for a new plain crate, `terra_motion` (docs/movement.md's, D28), with no Bevy in it. That covers the move sets as data, their phases, cancels and buffer, how a blow is taken (hit, blocked, parried, guard broken, dodged), what a move costs in stamina, and the blade swept against hurt capsules. The server will run these. What stays in `terra_creatures` is only what shows: spawning, reading intent, playing clips, flashes and sounds. A duel of two bodies driven by scripted intents is a plain test in `terra_motion`, run on every core (D406).

The crate grows into movement.md's top three layers (intent, mover, actions) as their stages land. It is one domain crate (D407), not a crate per feature.

What a clip gets wrong is found by TypeScript checks in `tools/characters` that read the exported model, as `phases.ts` does: no Rust build and no Blender, in seconds. That means hands or a held thing inside the body, a blow that does not cross in front, a shield not facing out, and a chain whose moves do not meet. It is fixed where the clip is made or exported, never in game code.

A move's stamina cost and what its contact sounds like are fields of its move set, not code.

## Why

The developers, 2026-10-24, on the plan for the prototype's second round: "Make sure as part of this you're keeping the project correctly modular to ensure build times and maintainability are at our heart". Earlier (D407): "its not just about build times tho to be clear, part of this is to reduce complexity of modules, improve scopiing, etc".

Today the runner's tests compile Bevy and every crate under creatures: the world, the base on screen, the walker and survival. A plain crate tests in seconds, a server can run it without a window, and an agent reads its rules without the drawing. Checking clips where they are exported keeps the five rounds of the troll fight (troll-fight.md) from recurring: there, each defect was patched in the scene that played it.
