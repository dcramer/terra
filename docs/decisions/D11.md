# D11: Engine selection criteria

Area: Engine and code · Owner: Design · By: Developers · Status: Decided

Everything in Rust. Within that, the simplest stack that works well with coding agents and lets us reuse existing tech.

## Why

Decided by the developers on 2026-10-06, for performance, one language, and compiler-checked agent code, accepting that rebuilding in Rust cost weeks before the game was back to where the Godot demo was (was D27). Replaces the earlier criteria, which only preferred Rust.
