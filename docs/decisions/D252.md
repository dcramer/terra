# D252: Whether the terrain shares building's materials

Area: Building · Owner: Design · By: Agent · Status: Decided

Yes: the terrain and building share one library of materials (textures, height and shading, `assets/materials`, read through D290's reference packs, `assets/data/packs`, and texture arrays), so stone in a wall and stone in a cliff read as the same stone and a new material serves both, while each keeps its own drawing. Building's pack format and arrays are made so the terrain can read the same packs; the terrain is moved onto them later, as its own change.

## Why

Raised by the developers on 2026-10-13 with D251: "the same system used for roof materials (and terrain? idk)". Left to the agent on 2026-10-14 with every open call: "Like get it done".
