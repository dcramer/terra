# D40: Materials in voxels

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

Voxels carry a material as well as a shape, from the first version of the terrain. Removing terrain reports the volume of each material taken.

## Why

Built and in use since 2026-10-11 (`terra_voxel`): the pickaxe digs stone and ore by volume. The technical reading of "organic harvesting": resources are in the ground and digging yields them. Adding materials to a shape-only terrain later would mean redoing its storage, meshing and edits. Voxel Tools already does this, so there is a design to port.
