# D12: Engine

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

Bevy (0.20, D31) as the framework, with our own voxel terrain ported from the parts of Voxel Tools we need.

## Why

Follows from D11. Bevy supplies renderer, entity system, windowing, assets, audio and UI, so we do not write those. Toolchain proven in [research/rust-stack-spike.md](../../research/rust-stack-spike.md). Reopen if the terrain port cannot match the Godot numbers. The Godot build was retired on 2026-10-12, before the Rust build had passed the same checks: its numbers stay the bar, in [research/godot-spike.md](../../research/godot-spike.md), and its code is in git history.
