# D618: The alpha-mask prepass draws its materials in their draw priorities, tall crowns first and the far woods last

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

Bevy 0.20 draws a binned phase's batch sets in key order, which is the order their pipelines were made in: at the lake the far woods' cards first, then the undergrowth, then the conifers' crowns, so the cut-outs nearest the camera write their depth last and every far card behind them runs its alpha test for nothing. A material now says where its meshes draw in the alpha-mask depth prepass, lowest first, as Godot's `render_priority` sorts materials ahead of their key and Unreal's translucency sort priority a primitive ahead of its distance. A patch of `bevy_render` and `bevy_pbr` 0.20.0 (D184), marked `Terra's patch (D618)`:

- `bevy_render`'s `render_phase/mod.rs`: `BinnedRenderPhase::draw_priorities`, a batch set's priority where it was given one (`set_draw_priority`; 0 is not kept), pruned only once it outnumbers the phase's batch sets; `batching/mod.rs`'s `sort_binned_render_phase` sorts the multidrawable and batchable batch sets by (priority, key) when a phase has any priority and `DRAW_PRIORITIES` is on, and by key alone otherwise, Bevy's order.
- `bevy_pbr`: `Material::prepass_draw_priority` (default 0), `MaterialExtension::prepass_draw_priority` (`None` takes the base material's), carried in `PreparedMaterial`; the non-deferred alpha-mask prepass queue gives its batch set the material's priority.
- The priorities: `terra_sandbox`'s lush `FoliageExtension` (the woods' crowns, with the lush experiment's floor cards and ivy, one type) -1, `terra_world::grown`'s (the undergrowth) 0, `terra_world::woods`'s `FarExtension` (the far woods) 1.
- The tunable `render.draw_priorities` (`terra_world::gpu_bookkeeping`, default 1) sets `DRAW_PRIORITIES` each frame; at 0 the phase draws in Bevy's order, so a probe measures the one against the other in one load (D609).

A priority is per batch set (pipeline, material bind group, slabs): materials sharing one take the last given. Only the alpha-mask prepass reads it; the opaque prepass, the main passes and shadows keep Bevy's order. Upstream: Bevy's main has no material draw order for binned phases (2026-11-04). Not yet offered.

## Why

The lake's route view (1901x1550, the worker's 4090), `render.draw_priorities` 0 against 1, three loads (job 20261104-085806-3846-patch): the early prepass 0.946 -> 0.911, 0.953 -> 0.918, 0.945 -> 0.908 ms, a saving of 0.035-0.037 ms in every load with an A/A of 0.001-0.002; the frame 7.018 -> 6.999 (A/A 0.045), 6.931 -> 6.881 (0.001), 6.978 -> 6.980 (0.018), within the noise in two loads. With no material giving a priority the two are the same to the microsecond (j23). It draws the same: the route view shot twice in each order (job 20261104-085841-ec86-patch) differs between orders by an RMSE of 0.0114-0.0121, its shots in one order by 0.0108-0.0113, TAA's frame-to-frame spread.
