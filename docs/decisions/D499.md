# D499: A cleared dungeon stays cleared

Area: Worlds and realms · Owner: Design · By: Developers · Status: Decided

A dungeon players have cleared stays cleared: it does not fill again over time or come back with a new seed. This is the default to build on; whether some dungeons fill again is found out as the game is played.

## Why

Asked whether a cleared dungeon stays cleared, fills again over time or comes back with a new seed, the developers on 2026-10-25: "nah, stays cleared, we can figure it out as we go, but that's a healthy default". Was the agent's default, a new seed each visit.
