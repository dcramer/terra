# D538: A round agent carries the routine

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Decided

A coordinator starts every build round with the `round` agent in `.claude/agents/` and isolation "worktree". The agent file holds the routine: seed and pull, one plain command a call, edits by Edit and Write, scratch in the worktree's `target/round/`, waits on completion notices, the step-back and bound rules, and the handoff and report with `FOR REVIEW:` and `FOUND:` lines. The brief says only the task, the skill, the bound and the handoff files.

## Why

The developers, 2026-10-27: "Yes: build the round agent type". The transcripts of 2026-10-24 to 26 (12 sessions, 200 subagents) show coordinators writing about 180 briefs of 2 to 7k characters by hand, each restating AGENTS.md's routine in its own order. The rounds lost about 770 turns to refusals: 565 by the worktree guard (chained `cd`/git commands, Python heredoc edits, a variable holding the coordinator's scratchpad), 127 by the wait-loop hook and the sleep block, and 75 `update_plan` calls a subagent cannot make. Two rounds once ran in one worktree. A round's own file fixes these once instead of in every brief.
