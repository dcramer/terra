# D41: Generation toolkit

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

One shared crate, `terra_gen`, for seeds, noise and repeatable random streams, giving the same result on every machine. Built first. Everything generated is a function of the seed and a position; only changes are stored or sent.

## Why

Built and in use since 2026-10-10, its outputs pinned and checked on three platforms. Follows from D8. Terrain, materials, scattering, plants and sky all need it, and D21 and D29 depend on every machine generating the same world.
