# D43: What can be harvested

Area: Worlds and realms · Owner: Design · By: Agent · Status: Leaning

Possibly rock and ore by mining, trees by chopping, grass by cutting. Likely every plant can be harvested except short ground cover; tall grass and reeds can, giving fibre (2026-10-12). Things grow back (D150).

## Why

The engine supports all three kinds (ground, objects, cover) through one contract, so this can stay open. See [engine.md](../engine.md).
