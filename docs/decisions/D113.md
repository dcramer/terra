# D113: How sound is put together

Area: Art, characters and sound · Owner: Tech · By: Agent · Status: Decided

Gameplay says what happened as a `Noise` (what, where), or it is heard from state it already shows; one module decides what each noise sounds like. Sounds are entities with a `Voice` (part of the mix, level), so the options menu's volumes reach what is already playing. Walkers carry `Footsteps`, sounding things carry `Ambient` and play only within earshot. Clips come from named sets with several takes; air, water, fire, birds and music are generated in code. Bevy's own audio, no new dependency. Scripted runs are silent but report what they would have played; WSL is silent unless `--sound`.

## Why

Asked for by the developers on 2026-10-11, done systemically and in ECS. A noise as a fact rather than a file keeps gameplay free of sound, and lets creatures hear it later. Bevy's audio has no reverb or muffling; `bevy_seedling` is the candidate if we need them. See [audio.md](../audio.md).
