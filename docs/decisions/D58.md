# D58: How the game is modelled in code

Area: Engine and code · Owner: Tech · By: Developers · Status: Decided

In ECS. Everything in a world is an entity; its state is components; behaviour is systems. Resources only for what is truly one of a kind. The client and the server both hold the world this way. Rules that every machine must agree on stay in engine-free crates (D28) and are called from systems.

## Why

Asked for by the developers on 2026-10-10. It is how Bevy works, it lets a thousand players and their things be processed in bulk, and it keeps D28: the rules are plain functions, the ECS holds the state. What belongs to a player is a component of the player, the builder and inventory included (done on 2026-10-12, [research/ecs-audit.md](../../research/ecs-audit.md)).
