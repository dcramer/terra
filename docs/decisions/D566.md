# D566: Assembled items' parts join on one line, made in the finished frame and never scaled; the kinds are data in assets/data/kinds

Area: Items and crafting · Owner: Tech · By: Agent · Status: Decided

Each part of an assembled item (D565) is made in the frame it has in the finished item, on glTF axes (D303) and facing as its mount says (D546), so assembling never turns it. Every item has one line, its +Y; a join along a handle is a position on it and a diameter, and only a shield's boss and rim and a bow's nocks are full points (a position, a direction and an up). Parts are placed by a shift along the line or one rigid transform, never scaled; code-made handles take each join's diameter from its partner, so they fit exactly. The item's grip, second grip and edge are its parts' points carried through ([assembled-items.md](../assembled-items.md#the-connection-point-convention)). The kinds are one JSON file a move-set class in `assets/data/kinds/`, with a JSON Schema beside them that refuses a blank, read by the kind and part checks and at run time by the assembler.

## Why

D565's step 1, which the developers approved: "Yes, step 1". The research behind it: a resized part floats off its partner (Bannerlord), a join is a slot with one diameter and a handle made to it ([parts as art](../../research/2026-10-28-assembled-parts-art.md)), and the grip, second grip and edge must come from the handle's and head's own points, not the mesh ([assembled equipment](../../research/2026-10-28-assembled-equipment.md)). One line and parts made already facing keep assembly a translation, the simplest transform to make exact and to check. The table is in the asset root because the assembler reads it in play and on the server (the [pipeline note](../../research/2026-10-28-assembled-items-pipeline.md)); JSON so the TypeScript checks need no parser and a schema can hold it. Decided by the agent (a technical call) once step 2's checker ran it: the part checker measures every join where the assembler places it (`terra_items::assembly::meet`, the one placing rule), and both refuse what breaks it.
