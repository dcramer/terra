# D23: Development workflow

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Decided

One Cargo workspace. `cargo test` runs everything with no GPU. Screenshots come from the Linux build under WSL's software renderer; performance is measured on the Windows build, cross-compiled from WSL, and natively on macOS. Toolchain, Bevy, Blender (`tools/blender/version`) and all dependencies are pinned. Debug builds keep line numbers only.

## Why

Each step was exercised in the toolchain check except macOS. Full debug information made a Windows build too large to load.
