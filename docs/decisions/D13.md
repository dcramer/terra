# D13: World scale

Area: Worlds and realms · Owner: Design · By: Developers · Status: Decided

Always round, fully procedural, and large but finite: walking all the way round should be a ridiculous task. The game's world is the 30 km realm (189 km round, 12 hours on foot), with its mountains, lakes, latitudes and woods: every world a player makes, from the title screen or the command line, is made at it, and keeps the radius it was made at with its save. Others are 10 to 50 km, set by theme (a proposal until a second realm has one).

## Why

The developers set the intent on 2026-10-10 and asked for numbers that feel good. On 2026-11-04 they made the 30 km world the game's: "we have these demos like lakes, and mountains and settlements with buildings but NONE of that shit is in the main game, like if i start a launch screen and then run any worlds, its old shitty-ass assets for trees, ground and etc. can we pull those in and make sure THEY are core part of the game?" Rendering cost measured the same at 2 km and 20 km in the retired Godot spike. Needs positions relative to a moving origin, and 64-bit on the server (D36). See [worlds.md](../worlds.md#size). Was "about 2 km", which is under an hour on foot; a scripted run keeping no world still stands on that 2 km test planet, which its tools' fixed places and baselines are measured on, until they move to the game's.
