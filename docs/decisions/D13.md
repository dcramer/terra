# D13: World scale

Area: Worlds and realms · Owner: Design · By: Agent · Status: Leaning

Always round, fully procedural, and large but finite: walking all the way round should be a ridiculous task. Proposed: about 30 km radius for the starter world (189 km round, 12 hours on foot), and 10 to 50 km for others, set by theme.

## Why

The developers set the intent on 2026-10-10 and asked for numbers that feel good; these are a proposal until walked. Rendering cost measured the same at 2 km and 20 km in the retired Godot spike. Needs positions relative to a moving origin, and 64-bit on the server (D36). See [worlds.md](../worlds.md#size). Was "about 2 km", which is under an hour on foot.
