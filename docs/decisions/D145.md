# D145: Simulation level of detail

Area: Engine and code · Owner: Tech · By: Agent · Status: Decided

Creatures are simulated by how near the nearest player is: within 64 m every tick; within 256 m they move every tick but think once in eight, taking turns by a number from where each was put out (never its entity, which shifts with what formed first), and each rolls its own dice, seeded from that place, so one creature does the same in every run of a world (mine round 12); beyond, they wait where they are. Each has a `Detail`, worked out every tick (`play::lod`), which the systems that simulate it ask. Other kinds of thing join it as they need to. The distances are a first guess, to be measured.

## Why

Mine to decide, for D127 and a thousand players on one server: ticks go where someone can see the result. Simulation or AI LOD is how shipped open worlds keep many actors, as Unreal's significance manager does. Moving every tick at reduced detail keeps what is seen smooth; thinking less often is what saves.
