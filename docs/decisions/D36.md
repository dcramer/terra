# D36: Coordinates

Area: Engine and code · Owner: Tech · By: Agent · Status: Leaning

One coordinate frame per world, with positions relative to an origin that moves with the player, and 64-bit positions on the server. No solar-system frame and no `big_space`.

## Why

With no space (D4), nothing ever spans two worlds, so one frame per world is enough. Was "solar-system coordinates", adopting `big_space` when a second planet existed.
