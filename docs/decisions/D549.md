# D549: One GPU-free test compiles every shader as the game's pipelines specialize it

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Decided

Every file in `assets/shaders` is compiled and validated by one test (`terra_world`'s `shaders_tests`), without a GPU, through Bevy's own path: a headless app with no renderer loads Bevy's shader libraries and ours through the asset server, Bevy's `ShaderCache` resolves and composes each with WESL, and naga validates the result as wgpu would. Each shader gets the definitions the game's pipelines give it, read off the code that makes them, not guessed: a table of every material of ours (which file each stage is, how it blends, whether it is drawn into the prepass and the shadow maps, the attributes of its meshes, what its `specialize` adds) and the main camera's two quality presets, from which the forward, prepass and shadow pipelines are specialized as `bevy_pbr`'s `MeshPipeline` and `PrepassPipeline` do. Shaders that stand in for one of Bevy's (the skinning) are compiled in Bevy's place, through Bevy's mesh and prepass shaders. A file no material, pipeline or importer in the table names fails the test, so a new shader cannot go unchecked. It replaces the sky's and the skinning's own compile tests, which stubbed Bevy's modules by hand.

## Why

A shader that does not compile draws nothing at run time; the only sign is an error in the log, and scripted runs and films go on and pass. Sky stage 1 lost its clouds that way, to a function it had removed that the far land still called. Unreal fails the cook on a shader that does not compile; this is ours, in a few seconds, on every `cargo test`. The first cut compiled each file with one guessed set of definitions and failed 20 of 53 compiles on the guesses, not on bugs: eight shaders read the second UV unguarded because every mesh they are drawn on has one, ground's prepass branch is never used because no material names it as a prepass shader, and fire is never drawn in a prepass at all. Definitions read off the materials make a failure mean a pipeline the game would really make.
