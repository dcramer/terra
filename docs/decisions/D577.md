# D577: Tracy is the profiler for the detail

Area: Tools and workflow · Owner: Tech · By: Agent · Status: Decided

A `tracy` feature on `terra_sandbox` (terra_world's: Bevy's `trace_tracy` without `trace_tracy_memory`, with `hitch-log` so the recorder and the session report still run, and the client's `only-localhost`) makes a profiling build. `cargo xtask profile play --tracy`, the launcher's `Profiling: live (Tracy)`, builds it, opens Tracy's profiler on 127.0.0.1 and plays, the report written at quit; `cargo xtask profile walk --tracy` keeps a capture of the scripted walk capped at the walk plus 120 s (`tracy-capture -s`), in `logs/` with a CSV of every zone, and prints the costliest systems by total and by longest run (`tracy-csvexport`) beside the report's head, which name the same systems as the report of the same run. The pinned Bevy 0.20 (`tracy-client-sys` 0.30.1) is Tracy 0.14.1's client, Tracy's latest release (2026-08-22); the task fetches that release's tools from GitHub, checked against the SHA-256 the release publishes, into `%LOCALAPPDATA%\terra\tools\tracy-0.14.1` under WSL (`~/.cache/terra/tools/` elsewhere), never installed system-wide; `cargo xtask doctor` compares the client's own version header with `VERSION` and the tools' `-V`. Under WSL the game and profiler both run in Windows and meet on its localhost. Tracy is BSD 3-clause and its Rust client MIT or Apache 2.0 (D196); its client goes only into profiling builds. Times from a Tracy build are never a change's measure: the benchmark is (D185). [launcher.md](../launcher.md#live-tracy-d577).

## Why

The developer, 2026-10-29, asked for live profiling with Tracy. Bevy supports it and its profiling guide recommends it; it shows every span on a timeline live, which a log line or report cannot, and its captures are compressed and capped where a Chrome trace of four thousand frames ran to 17 GB (perf round 1). The developer allowed the download on 2026-10-29: "Yes, agents may download Tracy 0.14.1 from its official GitHub release into %LOCALAPPDATA%\terra\tools (not installed system-wide) and run it for profiling."
