# Spikes

Throwaway work that answers one question (D133). Each spike is a folder, `spike/<question>/`, with a README that states the question and where its findings go, normally a dated note in [research](../research).

- Nothing outside a spike depends on it: no skill, tool, doc or game code. When something starts to, move it to where it belongs first (`tools/`, a crate, `art/`).
- When its note is written, delete the spike. Git history keeps it.
- Its scratch output goes in an ignored folder inside it, and nothing kept lives there.

- [iso](iso/README.md): what a realistic 2.5D party game in the manner of Baldur's Gate II looks like on our engine. Its note is [research/2026-11-05-isometric-party-spike.md](../research/2026-11-05-isometric-party-spike.md); kept on the developers' ask (2026-11-05) to play while they judge it, then deleted.
